# Kiosk Project

A simple Python kiosk application that handles customer orders and payments, with receipts stored in SQLite.

## Features
- Display menu and take orders
- Add/remove items from cart
- Calculate total price
- Process payment and calculate change
- Store payment receipts in SQLite DB
